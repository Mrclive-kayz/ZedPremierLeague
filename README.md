# zedPremierLeague

zedPremierLeague is a personal project I'm developing to make information about the Zambian Premier League easier to access and explore. The application is currently focused on its backend, with REST APIs for teams, players, fixtures, results, league standings, and articles.

I'm building it using Java and Spring Boot to apply and improve my software engineering skills through practical experience with API development, relational databases, testing, and backend architecture.
